# حوالی پاییز | برای معصومه

یک وب‌سایت فارسی با نرگس‌های گرافیکی، حرکت شبه‌سه‌بعدی، برگ‌های پاییزی و متن‌های عاشقانهٔ ملایم.

## اجرا
فایل `index.html` را باز کنید، یا از یک وب‌سرور استاتیک استفاده کنید. نیازی به نصب یا build نیست.

## انتشار با GitHub Pages
در Settings → Pages، گزینهٔ Deploy from a branch را انتخاب کنید و منبع را روی `main` و `/(root)` بگذارید.

## امکانات
- طراحی راست‌به‌چپ و واکنش‌گرا
- حرکت صحنه با نشانگر ماوس
- نور صبح، عصر و شب
- افکت برگ‌های شناور
- پشتیبانی از تنظیم کاهش حرکت

گرافیک‌ها با SVG و CSS ساخته شده‌اند. فونت Vazirmatn از Google Fonts بارگیری می‌شود و Tahoma فونت جایگزین است.
